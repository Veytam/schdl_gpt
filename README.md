# schdl_gpt

Личный помощник для учебного Telegram-форума. Он собирает текстовые сообщения из всех тем в PostgreSQL. Codex ищет по архиву через MCP. Для мобильного ChatGPT можно обновлять отдельный приватный текстовый файл в Google Drive.

```text
Telegram → сборщик → PostgreSQL → MCP через SSH → Codex
                              ↳ выборка → Google Drive → ChatGPT
```

## Сервер

Понадобится Linux-сервер с Docker, systemd и SSH. База работает в отдельной Docker-сети без опубликованного порта. Сборщик использует существующий аккаунт Telegram с доступом к целевой группе и отдельную авторизованную сессию на сервере.

1. Скопируйте репозиторий на сервер. Узнайте числовой ID группы. Если Telegram даёт ссылку на сообщение вида `https://t.me/c/1234567890/42`, ID группы для Telethon будет `-1001234567890`.
2. Выполните из корня репозитория:

   ```sh
   sudo ./install-server.sh -1001234567890
   ```

   Подставьте реальный ID. Скрипт создаёт отдельный набор контейнеров, том PostgreSQL, локальные пароли и таймер очистки. Путь установки — `/opt/study-schedule`. Для уже существующей установки скрипт завершится без её перезаписи.
3. Авторизуйте Telegram в интерактивном терминале:

   ```sh
   ssh -t root@YOUR_SERVER /opt/study-schedule/telegram-login
   ```

   Введите номер, присланный Telegram код и пароль двухэтапной проверки, если он включён. После проверки доступа к форуму сборщик стартует автоматически.
4. Проверьте первую синхронизацию:

   ```sh
   ssh root@YOUR_SERVER 'docker logs --tail 20 study-schedule-collector'
   ```

Сборщик опрашивает форум примерно каждые пять минут. После сбоя дочитывает доступную историю по последнему сохранённому идентификатору. Он запрашивает историю и список тем, не отправляет сообщения и не вызывает команду отметки прочтения. При каждом проходе перечитывает публикации за последние два дня для учёта правок. Удаления в исходном Telegram и более старые правки не отслеживаются. Вложения не скачиваются.

История загружается за последние 175 дней. Таймер ежедневно удаляет целиком просроченные дневные секции PostgreSQL, освобождая место. Если сервер полностью выключен, очистка догонит расписание после запуска. Для сессии используется OpenTele с настройками клиента Telegram Desktop, как в исходном проекте. Это сторонний клиент Telegram.

## Codex

На компьютере, где работает Codex, настройте SSH-доступ к серверу и проверьте ключ хоста. Указанный пользователь должен иметь право запускать `docker exec` для контейнера базы. MCP отправляет только заданные запросы в транзакции только для чтения с ролью `schedule_reader`.

```sh
uv venv --python 3.12 .venv
uv pip install --python .venv/bin/python -r requirements-mcp.txt
codex mcp add study_schedule --env SCHDL_GPT_SSH_TARGET=root@YOUR_SERVER -- \
  "$PWD/.venv/bin/python" "$PWD/schedule_mcp.py"
```

Вместо `root@YOUR_SERVER` можно указать SSH-алиас, например `study-schedule`. Если переменная не задана, используется этот алиас. Откройте новый чат Codex и спросите: «Какие у меня завтра пары и что нужно сдать?»

## Google Drive и ChatGPT на телефоне

Этот шаг необязателен. Сервер обновляет приватный файл **«Учебное расписание и задания.txt»** каждые 15 минут. Выгрузка отбирает строки расписания, формулировки заданий и сроки по текстовым признакам. Она убирает найденные ссылки и телефонные номера. Нестандартные формулировки и задания во вложениях могут не попасть в файл, а ошибочная дата из объявления может сохраниться. Для точной проверки используйте исходную тему или Codex с полным текстовым архивом.

Запустите на компьютере с браузером:

```sh
ssh -t -L 127.0.0.1:53682:127.0.0.1:53682 root@YOUR_SERVER /opt/study-schedule/drive-login
```

Откройте ссылку из терминала, выберите свой Google-аккаунт и подтвердите доступ. Rclone запрашивает разрешение `drive.file`. После первой успешной записи скрипт включает таймер. В мобильном ChatGPT подключите плагин Google Drive к тому же аккаунту и попросите прочитать файл по названию.

Общий OAuth-клиент rclone выводится из эксплуатации. Для долгосрочной установки настройте [собственный клиент Google Drive](https://rclone.org/drive/#making-your-own-client-id) и авторизуйте его с областью `drive.file`. При смене клиента может понадобиться создать выгрузку заново и обновить ссылку в ChatGPT.

Проверка состояния:

```sh
ssh root@YOUR_SERVER 'systemctl list-timers study-schedule-drive.timer study-schedule-expire.timer'
ssh root@YOUR_SERVER 'systemctl status study-schedule-drive.service --no-pager'
```

## Код и конфигурация

| Файл | Назначение |
| --- | --- |
| `collector.py`, `Dockerfile` | Чтение форума и запись сообщений |
| `install-server.sh`, `init-db.sh` | Развёртывание и роли PostgreSQL |
| `telegram-login`, `start-collector` | Авторизация Telegram и запуск |
| `expire.sql`, `study-schedule-expire.*` | Очистка просроченных секций |
| `schedule_mcp.py`, `requirements-mcp.txt` | Доступ Codex через SSH |
| `drive_export.py`, `drive-login`, `study-schedule-drive.*` | Выгрузка в Google Drive |
| `smoke.py` | Проверка PostgreSQL, дедупликации и очистки на тестовых строках |

Конфигурация и секреты установки хранятся на самом сервере в `/opt/study-schedule`. Сессия Telegram, токен Google Drive, пароли PostgreSQL, реальные сообщения и история выгрузок не предназначены для Git.
